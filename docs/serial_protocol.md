# Serial Protocol

PC側は1行1 JSONとして受け取ります。

## hit

タンバリンを叩いたイベントです。PC側はこの受信時刻で音ゲー判定します。

```json
{"type":"hit","ms":12345,"power":812,"x":20,"y":-44,"z":1012,"energy":900}
```

- `ms`: ボード起動からのミリ秒
- `power`: 叩いた強さの目安
- `x`,`y`,`z`: 加速度のmg換算値
- `energy`: 前サンプルとの差分量

## raw

デバッグ表示用です。

```json
{"type":"raw","ms":12345,"x":20,"y":-44,"z":1012,"energy":100,"filtered":88}
```

## PC/MCUの役割分担

- MCU: 加速度から「叩いた」を検出して送る
- PC: 曲の再生時間に合わせて PERFECT/GREAT/GOOD/MISS を判定する

この分担にしておくと、あとで複数タンバリンや無線化をしても壊れにくいです。
